# Windows
Downlaod VencordInstaller.exe once installed open the app
![Windows setup image-1](https://monkeyman842.github.io/Vencord-tut-images/windows-1.png)
<br>
select file directory
- stable(recommended)
- Custom install location(not recommended)
<br>
If this is your first time downloading vencord click the green "Install" button
<br>
If you had vencord at one point and no longer works click the blue "Reinstall/Repair" button
<br>
If you had discord running this will close and reopen it
![Windows setup image-2](https://monkeyman842.github.io/Vencord-tut-images/windows-2.png)
<br>

# Linux
If discord is running ensure that it is fully closed
<br>
![Linux setup image-1](https://monkeyman842.github.io/Vencord-tut-images/Linux1.png)
<br>
Go to Vencord website and copy terminal command either by highlighting and hitting ctrl + c or by clicking the copy button
![Linux setup image-2](https://monkeyman842.github.io/Vencord-tut-images/Linux2.png)
<br>
Open the terminal from your search bar or by hitting ctrl + alt + t
<br>
![Linux setup image-3](https://monkeyman842.github.io/Vencord-tut-images/Linux3.png)
<br>
Paste copied command by using ctrl + shift + v
<br>
using ctrl + v will not work 
<br> 
hit enter and type in your password before hitting enter a second time
![Linux setup image-4](https://monkeyman842.github.io/Vencord-tut-images/Linux4.png)
<br>
Press enter when hovering "Install Vencord"
<br>
use the arrow keys to navigate the menu
<br>
if you had Vencord installed already but it broke due to an update still hit enter on "Install Vencord"
![Linux setup image-5](https://monkeyman842.github.io/Vencord-tut-images/Linux5.png)
<br>
the recomended thing to do is hit enter on "Stable" but if you wish to set a custom location hit enter when hovering "Custom Location"
![Linux setup image-6](https://monkeyman842.github.io/Vencord-tut-images/Linux6.png)
<br>
then reboot Discord
